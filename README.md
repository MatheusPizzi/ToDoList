# 📝 ToDo List

Um projeto simples de lista de tarefas desenvolvido com **HTML, CSS e JavaScript**, permitindo adicionar, marcar e remover tarefas do dia a dia.

---

## 🚀 Funcionalidades

* ✅ Adicionar novas tarefas
* ✏️ Marcar tarefas como concluídas
* ❌ Remover tarefas
* 💾 (Opcional) Persistência no navegador com LocalStorage

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

---

## 📂 Estrutura do projeto

```
ToDoList/
│── index.html
│── style.css
│── script.js
```

---

## ▶️ Como executar o projeto

1. Clone o repositório:

```
git clone git@github.com:MatheusPizzi/ToDoList.git
```

2. Acesse a pasta:

```
cd ToDoList
```

3. Abra o arquivo `index.html` no navegador
